# CLOUD · 2026-11-12 · 개발 회차 03

현관 앞 돌로 건네는 인사

## 쟁점과 가상 토론

8장에서 소녀는 노란 스카프를 기억해 달라고 한다. 기존 9장에서는 할머니 손을 잡으면 비행이 잠기고 가만히 있어도 다음 시대로 넘어갔다. 재회에서 손녀가 이전 장의 기억을 이어받는 순간을 플레이어의 행동으로 만든다.

| 역할 | 제안 | 구체적 반론에 대한 응답 |
| --- | --- | --- |
| A · 서사 디자인 | 할머니가 현관 돌에 빗방울이 떨어지던 소리를 떠올리게 하자. 손녀가 같은 소리를 알아듣거나 구름에게 손으로 인사한다. | B는 회상을 반복 과제로 만들면 재회의 여운이 줄어든다고 했다. 인사는 한 번이면 끝나고, 플레이어는 두 동작 중 하나를 고른다. |
| B · 레벨·플레이 | 현관 앞에서 돌에 비를 내리거나, 낮게 내려가 손녀에게 손을 내밀게 하자. | C는 두 동선을 위해 별도 구역이나 표식을 만들면 아트와 장면 전환을 다시 연결해야 한다고 했다. 돌과 손녀가 이미 함께 보이는 현관을 두 동작의 공통 기준으로 쓴다. |
| C · Unity 개발 | 할머니와 손을 잡은 뒤 비행을 돌려주고, 인사에 기존 비와 손 내밀기 입력을 연결하자. 선택에 따라 손녀의 대사와 자세를 바꾼다. | D는 이미 누르고 있던 F로 인사가 끝나거나 E와 F의 진행도가 합쳐질 수 있다고 했다. F는 새로 눌러야 하고, 다른 동작으로 바꾸면 이전 동작의 진행은 사라진다. |
| D · QA·VR 상호작용 | 두 인사의 입력 조건과 중단 복귀를 각각 검사하자. 인사가 끝난 뒤에는 R을 길게 눌러 떠날 시간을 직접 정하게 한다. | A는 산불 장의 조작이나 물 배분까지 바뀌면 인사의 의미가 흐려진다고 했다. 재회 장에서만 명시적으로 떠나며, 두 선택 모두 기존 산불 장 시작 상태로 이어진다. |

## 결정과 적용

- 할머니 손을 잡은 뒤 비행이 풀린다. 현관 돌에 조준하고 E를 길게 눌러 비를 내리거나, 가까이 낮게 날아 F를 새로 길게 눌러 손녀에게 인사한다. 비를 택하면 손녀가 돌을 바라보는 연결과 돌 소리를 알아보는 대사가 나온다. 손짓을 택하면 손을 내미는 자세와 인사 대사가 연결된다. 비의 물 4%는 인사가 완료될 때 한 번 소비된다. 인사 뒤 현관에 더 머물 수 있으며, R을 길게 누르면 산불 장으로 이어진다.
- `CloudStory.cs`에서 현관 기준점과 인사 목표를 정의했다. `CloudJourney.cs`에서 입력 조건, 두 동작의 독립된 진행, 출발을 처리한다. `CloudHud.cs`와 `CloudWorld.cs`는 같은 상태로 안내와 자세를 갱신한다. 기존 키 매핑, 아트, 장 단위 저장 형식을 사용한다.

## 실행한 검증

- 원본과 변경본의 `CloudStory.cs`, `CloudJourney.cs`를 .NET 8에서 컴파일하고 `CloudVerify.Story()`의 규칙 검사를 실행했다. 검사에 쓰는 Unity 수학 호출 두 개는 표준 수학으로 실행했다. 변경 전에는 할머니 손을 잡은 뒤 비행 잠금과 무입력 전환이 재현됐다. 두 버전 모두 물방울 합체, 열 시대, 산불 구출과 순환을 통과했다.
- 변경 후에는 8장 현관 작별 → 9장 손짓 인사 → 10장 산불과 별도로 9장 재진입 → 돌에 비로 인사 → 10장 진입을 검사했다. 길게 누른 F의 자동 재사용, 잘못된 조준과 거리, 인사 중 조작 전환, 완료 후 물의 중복 소비, 무입력 대기, R 출발, 산불 장의 초기 물과 재진입을 확인했다. `python3 Tools/verify_story_offline.py`와 `python3 Tools/verify_package.py`도 통과했다.
- Unity Play Mode, 실제 키보드 완주, 서사 반응의 화면·음향 타이밍, PlayerPrefs 재시작 복구, PC 빌드, 외부 플레이테스트, 교체 모델 동선과 헤드셋은 이번에 실행하지 못했다.
