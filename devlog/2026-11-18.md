# CLOUD · 2026-11-18 · 개발 회차 09

## 쟁점과 가상 토론

Unity가 없어 8~10장 키보드 검증은 보류했다. 직전 회차의 재회 출발 뒤에 이어지는 산불 대피에서, 손녀 바로 위에 있으면 아무리 높이 떠도 동행이 진행되는 규칙을 확인했다. 로드맵 02의 대피를 보완했다.

| 역할 | 제안 | 반론과 응답 |
| --- | --- | --- |
| 서사 디자인 | 길을 연 구름이 낮게 돌아와야 손녀가 함께 이동하게 한다. | 레벨 담당은 너무 낮으면 탐색이 어렵다고 했다. 저고도 접촉을 요구하지 않고 지면 위 30 미만의 범위를 둔다. |
| 레벨·플레이 | 고도가 높아지면 현재 위치에서 기다리게 한다. | QA는 반복 상승이 진행을 리셋하면 부담이라고 했다. 이동 진행과 물을 그대로 보존한다. |
| Unity 개발 | 기존 수평 반경에 고도 조건을 추가하고 HUD에서 하강을 안내한다. | 서사 담당은 비나 손 내밀기까지 달라질 수 있다고 했다. 대피 이동에만 적용하고 기존 행동과 장 전환을 사용한다. |
| QA·VR 상호작용 | 세 대피 구간에서 높이 경계, 거리 이탈, 하강 후 복귀를 검사한다. | 개발 담당은 키 전용 판정에 의존하지 말자고 했다. 기존 위치·고도 표본으로 재현하고 기기 검증은 남긴다. |

## 결정과 검증

`CloudStory.cs`의 고도 한계를 `CloudJourney.cs` 대피 규칙과 `CloudHud.cs` 하강 안내에 연결했다. 손녀는 구름이 멀거나 높으면 멈추고, 근처에서 내려오면 다음 안전 지점으로 이어서 이동한다. 마지막 대피 뒤 기존 희생과 순환 엔딩은 그대로 이어진다.

- .NET 8에서 실제 C# 규칙과 `CloudVerify.Story()`를 실행했다. Unity 수학 호출 두 종류는 표준 수학으로 대체했다. 새 검사에서 기존 이동 규칙이 실패했고, 수정 후 세 구간에서 높이 경계의 정지, 물과 이동 지점 보존, 하강해 재합류를 통과했다.
- 오프라인 스토리·패키지 검사 통과. 장 재진입, 8장 작별, 9장 두 인사와 R 출발, 10장 산불과 순환, 에셋 GUID 97개와 참조를 검사했다.
- Unity Chapter Review·Play Mode, 키보드 실제 조준·비행, PC 빌드, 에디터 재시작 후 저장, 외부 플레이테스트, 실제 모델 교체 및 VR 헤드셋은 미검증이다.
